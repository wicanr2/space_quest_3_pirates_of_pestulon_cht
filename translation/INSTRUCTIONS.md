# 宇宙傳奇 III：Pestulon 的海盜 SCI0 EGA 繁中化 — 翻譯 subagent 統一指令

你在翻譯 Sierra 1989 經典**搞笑科幻**動作冒險遊戲《Space Quest III: The Pirates of Pestulon》(宇宙傳奇 III) SCI0 EGA 原版。主角是銀河系最廢的清潔工英雄 **羅傑·威爾科**，這次要從邪惡軟體公司 **廢渣軟體(ScumSoft)** 手中救出被綁架的遊戲設計師「仙女座雙傑」。全片充滿美式惡搞、科幻/流行文化戲仿、雙關與吐槽。**先讀完本檔再翻你那批**。譯名一律照下方權威詞表。

## 輸入 / 輸出格式

- 輸入是一個 `.tsv`：每行 `英文原文 <TAB> 英文原文`(col2 是待翻底稿)。
- 輸出**同名 `.done` 檔**：每行 `英文原文 <TAB> 繁體中文譯文`。
- **col1(英文原文)一字不改**——它是引擎查表 key，改了就對不上、退回英文。逐行對齊，行數不變。

## 硬規則(違反就壞)

1. **佔位符 `%s` `%d` `%c` `%x` 原位、原數保留**。中文語序可調，數量與型別不可增刪。例：`You have %d buckazoids.` → `你有 %d 元太空幣。`(一個 %d)。
2. **控制碼保留**：`\r\n`/`\n`(硬換行)、開頭的 ` #` 選單標記、句中特殊序列，位置數量不動。
3. **繁體中文 + Big5 可編字**。不要簡體字、不要 Big5 打不出的罕字/顏文字/emoji。標點用中文全形：，。、：；！？「」『』…—。
4. **長度別暴增**(顯示有限)：譯文控制在原文語意內，別加註解、別擴寫。斷行交給引擎，**不要自己加 `\n`**(除非原文本來就有)。
5. 純功能性/系統字串照直譯(選單、錯誤提示、parser 回應)；有戲的對白/敘述才發揮語感。
6. **選單列帶前後空白**(如 `   Restore   `)：空白逐字保留，只譯可見字。
7. **parser 玩家輸入指令不翻**：`look`、`talk`、`get`、`open` 等玩家用鍵盤打的動詞是給引擎解析的，遇到「純指令字串」保留原文。看得到的敘述才翻。

## 風格尺度(搞笑科幻・台式在地化【重】)

- **總基調**：美式惡搞科幻喜劇。敘述/旁白像一個愛吐槽的說書人，對白誇張、活潑、口語。
- **台式在地化【重】**：雙關、笑話、戲仿**重寫成台灣觀眾接得住的梗**，笑點優先於字面直譯。可用台式自然語感與吐槽口吻(像「這下好了」「你是在哈囉」的自然程度，但**別濫用網路流行語/時事梗**以免快速過時)。西方流行文化戲仿(星際大戰、魔鬼終結者等)若台灣觀眾也熟就保留並點到。
- **羅傑·威爾科**：倒楣、嘴賤、其實善良的清潔工英雄。旁白常吐槽他。第二人稱一律「你」。
- **死亡訊息**：SQ 系列招牌——死法荒謬 + 吐槽玩家。翻得幸災樂禍、俏皮。
- parser 回應(打錯指令)：簡潔俏皮，如 `You can't do that.` → 「這你辦不到啦。」
- **不犧牲正確性**：玩法提示、方向、數量、物品名等資訊性內容要精準，別為了搞笑扭曲原意。
