## 故事背景

羅傑·威爾科在《宇宙傳奇 II》結局中，九死一生地逃離了史拉吉·沃霍爾的小行星要塞。他跳進逃生艙、按下發射鈕，在要塞於拉比翁大氣層中燒毀的前一刻脫離現場。

升空不久後，他發現逃生艙的氧氣即將耗盡。為求活命,他做了最後一搏——爬進休眠艙,只盼有人能盡快發現他。

如今,不知過了多久,這艘小小的逃生艙仍在深空中漫無目的地漂流。我們的主角在懸浮動畫中,時間彷彿靜止了。

**開場漫畫旁白**：與此同時，在達邦斯卡星系一顆不起眼的小行星上，我們看到一戶典型外星家庭的起居間——媽媽和孩子們正圍在影視機前，端著電視晚餐，準時收看新一集的《我愛露西》（原文雙關 *I Love Lucite*，「露西」諧音塑膠原料 Lucite）重播……

## 安裝與啟動（DOS 時代原版設定，ScummVM 玩家可略過本節）

> 以下為 1989 年原版磁片時代的安裝流程，僅供保留歷史紀錄之用。透過 ScummVM 遊玩不需要進行以下任何步驟，直接指定遊戲資料夾即可執行。

### 通用備份提醒

建議先備份母片，延長母片壽命並避免意外損毀；若使用磁碟片遊玩（非硬碟安裝），另需格式化一張空白磁片做存檔專用。

### MS-DOS

1. 將磁片 1（或其備份片）放入磁碟機，輸入磁碟機代號加冒號（如 `A:`）後按 ENTER。
2. 輸入 `INSTALL` 並按 ENTER，依畫面指示以上下方向鍵選擇。系統會詢問是否安裝到硬碟；不想安裝則按 ESC 跳過，否則輸入硬碟代號（通常是 C）並依提示完成。
3. 注意：安裝程式會在磁片 1 寫入一個名為 `RESOURCE.CFG` 的檔案，因此磁片 1 **必須未設寫入保護**。
4. 啟動方式：磁片版輸入 `SIERRA` 並按 ENTER；硬碟版先 `CD \SIERRA`，再輸入 `SQ3` 並按 ENTER。

### Atari ST

- 磁片版：磁片 1 放入 A 槽，開啟磁片圖示，雙擊 `SIERRA.PRG`。
- 硬碟版：雙擊硬碟圖示 → 開啟遊戲資料夾 → 雙擊 `SIERRA.PRG`。
- 若使用無記憶體擴充的 Atari 520 ST，執行遊戲時請勿掛載任何桌面配件（Desk Accessories）。
- **硬碟安裝步驟**：確認硬碟可用空間足夠（每片磁片約需 80 萬位元組）→ 建立遊戲資料夾 → 逐片將磁片內容拖曳複製進資料夾 → 母片收好保存。
- **選擇音樂裝置**（若支援音效卡）：執行磁片內的 `MUSIC.PRG`，在 Options 選單選「Music Device」，選擇你的合成器（或「Atari ST Internal Sound」內建喇叭），按 OK，再從 File 選單選「Install Game」寫入設定。務必在啟動遊戲前先開啟合成器電源。

### Amiga

- **磁片版**：以 Workbench 開機，磁片放入 A 槽，雙擊磁片圖示。若遊戲有多片磁片，備份片的圖示名稱如帶有「COPY OF」字樣，務必重新命名移除該字樣，否則系統會持續要求插入原始磁片而無法執行。
- **硬碟版**：開啟 Workbench → 雙擊硬碟圖示 → 開啟對應的 Sierra 遊戲資料夾 → 雙擊遊戲圖示。

## 操作方式

### 移動角色

可用方向鍵、數字鍵盤或滑鼠移動角色。用數字鍵盤時按 `5` 或再按一次剛才的方向鍵可停止移動；用滑鼠則按左鍵點選想讓角色前往的位置即可開始移動。

```
        N (↑)
   NW        NE
W (←)  停止  (→) E
   SW        SE
        S (↓)
```
（對應數字鍵盤 7/8/9、4/5/6、1/2/3 的八方位＋置中停止鍵）

### 遊戲速度控制

有時放慢動畫速度有助於通過刁鑽的關卡，或仔細觀察畫面細節。《宇宙傳奇 III》可用 `+`／`-` 鍵，或從 Speed 選單（滑鼠或方向鍵操作）調整速度。

### 快速鍵一覽

| 按鍵 | 功能 |
|---|---|
| F1 | 說明 |
| F2 | 開關音效 |
| F3 | 重複上一指令 |
| F5 | 存檔 |
| F7 | 讀檔（restore） |
| F9 | 重新開始遊戲（從頭開始） |
| CTRL-C | 取消目前輸入的指令列 |
| CTRL-I | 開啟物品欄 |
| CTRL-J | 重置搖桿 |
| CTRL-P | 暫停遊戲 |
| CTRL-Q | 結束遊戲 |
| CTRL-R | 切換 RGB／複合訊號顯示模式 |
| CTRL-S | 變更遊戲速度 |
| CTRL-V | 變更音量 |
| `+` | 增加音量 |
| `-` | 減少音量 |

### 選單操作

按 ESC 會在畫面上方叫出選單列，列出可用的指令選單。

- 左右方向鍵：開啟選單
- 上下方向鍵：選單內移動反白
- ENTER：確認選擇的指令
- ESC：不選任何指令、直接返回遊戲

## 與遊戲互動：輸入指令

本作採文字指令輸入，可以打一到兩個單字，也可以打完整句子。除非另有說明，輸入完指令後一律按 ENTER 送出。

### 範例指令

遇到會跟你講話的角色時，開啟對話：輸入 `TALK TO`（想交談的對象）。例如：`TALK TO THE PIRATE`（跟海盜交談）。

沿途會遇到各種物品，要撿取時輸入 `TAKE`（想拿取的物品）。例如：`TAKE THE SILVER CHALICE`（拿起銀製聖杯）。

### 觀察細節

多注意細節、仔細查看物品。輸入 `LOOK`（想查看的物品）。例如：`LOOK AT THE TREASURE CHEST`（查看寶箱）。

### 使用與交付物品

旅途中取得的物品需要善加利用。輸入 `GIVE THE OBJECT`（把物品交給某人或某物）。例如：`GIVE THE BONE TO THE HUNGRY TIGER`（把骨頭給那隻餓虎）。

### 重複指令

想重複上一個指令，可在 ACTION 選單選 RETYPE，或直接按空白鍵。

### 物品欄

想查看身上攜帶的物品，可在 ACTION 選單選 INVENTORY，或按 TAB 鍵。畫面會列出所有攜帶物品；用滑鼠點選或方向鍵反白某物品名稱、按 ENTER 即可查看該物品的細節說明。按 OK 或 ESC 返回遊戲。

### 暫停遊戲

在 ACTION 選單選 PAUSE 即可暫停遊戲；按 ESC 或 ENTER 恢復。

### 存檔

在 FILE 選單選 SAVE 存檔。建議經常存檔，讓自己有空間放心嘗試新方法、大膽探索——萬一出了意外，也不必從頭重來。遇到危險狀況前務必先存檔；每次遊戲有明顯進展後也建議存一次檔。

> 注意：若以磁片遊玩，存檔前磁片必須先完成格式化，否則無法存檔。

存檔名稱可自由命名，例如站在沙灘上時，可以把存檔取名叫「站在沙灘上」，或任何你覺得好記的說法。

### 讀檔

在 FILE 選單選 RESTORE，系統會列出可讀取的存檔（單磁碟機系統會提示插入存檔磁片）。反白想要的存檔後選 RESTORE 即可讀取；若存檔在別的目錄，選 CHANGE DIRECTORY 切換。

### 結束遊戲

在 FILE 選單選 QUIT 即可離開遊戲。

*（若沒有滑鼠，用 TAB 鍵在選單間反白選取。）*

## 新手冒險者小提示

如果你從沒玩過 Sierra 的冒險遊戲，這裡有幾個入門建議。

### 與《宇宙傳奇 III》互動的方式

遊戲指令由簡單的「動詞＋受詞」組成。例如 `GET INTO THE RAIL GRABBER` 可以簡寫成 `GET IN GRABBER`；`GIVE SIX BUCKAZOIDS TO THE CLERK` 也可以說成 `GIVE MONEY TO CLERK`。

《宇宙傳奇 III》能理解相當多常見動詞，以下列出一些常用的（保留英文原字，因為遊戲需要輸入英文指令）：

| | | | |
|---|---|---|---|
| LOOK（查看） | DROP（丟下） | EXAMINE（檢查） | USE（使用） |
| CLIMB（攀爬） | GET（取得） | READ（閱讀） | TALK（交談） |
| HIT（打擊） | PICK UP（撿起） | PLAY（玩／彈奏） | KICK（踢） |
| PUNCH（揮拳） | PUSH（推） | PULL（拉） | MOVE（移動） |
| OPEN（打開） | CLOSE（關閉） | GIVE（給予） | PUT ON（穿上／放上） |
| STAND（站起） | TAKE OFF（脫下） | SIT（坐下） | JUMP（跳躍） |

### LOOK（到處查看）

每到一個沒去過的新地方，或注意到新東西時，第一件事就是輸入 `look`（查看四周）。首次進入某個場景時輸入 `look`，會得到該場景的整體描述——請仔細閱讀，裡面常藏著提示，暗示畫面中有什麼東西值得進一步調查。

如果你站得夠靠近某個特定物件，可以再靠近細看，例如 `look at spaceship`（查看太空船）。每輸入完一句指令，記得按 ENTER 送出。

遊戲中每次輸入指令、或觸發任何訊息時，畫面都會跳出提示視窗；讀完提示後按 ENTER 關閉視窗、繼續遊戲。

### 探索（EXPLORE）

仔細探索遊戲中的每一處場景。在垃圾貨輪上四處搜尋逃脫的方法；每到一個星球也要仔細搜索每個角落——但要小心，這裡處處是危機。

### 畫地圖

建議畫一張地圖，記下去過的地方、找到的物品、危險區域，以及沿途看到的重要地標。漏看某個區域，可能就會錯過完成任務所需的重要道具或線索。

### TALK（交談）

盡量跟遇到的每個角色交談，但要有判斷力！有些角色友善又樂於幫忙，有些則會誤導、俘虜甚至殺死你。有時得硬碰硬打一架，有時則得逃跑、躲藏，或用智取的方式擺脫對手。

### PICK UP（撿取）

沒被釘死的東西都撿。你會沿途遇到許多之後派得上用場的物品，有些能直接撿，有些得用買的或交換取得。隨時按 TAB 鍵可查看目前身上的物品清單。

### USE（使用）

善用手上取得的物品來解謎。有些謎題答案很直覺——渴了就喝水；要買東西，就得準備好太空幣（buckazoid）；其他謎題則需要更多想像力才能破解。

### BE CAREFUL（小心行事）

隨時保持警覺——災難往往在最意想不到的地方降臨。

### 常常存檔

尤其是準備嘗試新方法、或可能有危險的動作之前，一定要先存檔。這樣萬一出了最壞的狀況，也不必從頭重新開始。（存檔操作方式見前述章節。）

### 別輕易氣餒

遇到看似無解的障礙，別灰心。多探索一下遊戲其他部分，之後再回頭試試看。遊戲裡每個謎題至少都有一種解法，有些甚至不只一種；有時某種解法會讓下一關變難，有時反而變簡單。卡關的話，不妨退回較早的存檔點，換條路試試。真的束手無策，也可以向原購買遊戲的經銷商購買《宇宙傳奇 III》官方提示本。

## 新手引導攻略（內含劇透，謹慎閱讀）

> **警告**：以下內容僅供新手冒險玩家參考,內含部分謎題解答與提示,老手玩家可能不想看到這些內容。**只有在卡關卡得受不了時再往下讀。**

角色走出逃生艙、艙門關閉後，你就正式取得角色控制權，遊戲開始。

按 ENTER 關閉艙門關閉後跳出的提示畫面。

用滑鼠、鍵盤或搖桿操控角色向南（往下）走，前往下一個場景——那裡堆放著幾艘報廢的太空船。

到了這裡，不妨先仔細看看四周：

- 輸入 `look`（查看四周）
- 走到太空船旁，逐艘輸入 `look at ship`（查看太空船）
- 走到一堆廢棄物旁，輸入 `look at junk`（查看廢棄物）
- 走到左前方的箱子旁，輸入 `look at crate`（查看箱子）

從這裡向東（右）走到下一個房間：

- 走到左前方的巨大齒輪旁，輸入 `look at gear`（查看齒輪）
- 走到背景中的巨大機械臂旁，輸入 `look at arm`（查看機械臂）

該探索的都探索完後，往房間右側走，會看到一台把桶子往上、往畫面外吊起的垂直輸送帶。靠得夠近的話，輸送帶會把你捲上去，接著送上一條水平輸送帶，直通碎料機——**這裡建議先存檔**。

為了不被丟進碎料機，輸入 `stand`（站穩），時機要抓在被輸送帶送到上方之前。接下來你就能沿著軌道開始探索整艘船，**但務必小心**！稍有不慎仍可能滑落摔死。提醒：如果你原本用滑鼠或搖桿操作角色，走這種驚險路段時，建議改用方向鍵操作比較精準。

走上軌道後，向西（左）走，會來到船體隔艙的一處開口。開口另一側、掛在軌道上的是一台軌道吊車（rail-grabber car）。走近後輸入 `get in grabber`（登上吊車），你就正式踏上探索這片新環境的旅程了。

祝好運，別忘了——仙女座雙傑正等著你來救呢！

## 需要提示嗎？

若在遊玩過程中「有點卡關」，可以試試以下管道（皆為 1989 年美國原版當時的服務資訊，現已停用，僅供歷史保存）：

1. **數據機撥接 Sierra 布告欄系統（BBS）**：(209) 683-4463，站長很樂意提供協助。
   設定：1200BPS、8 資料位元、無同位檢查、1 停止位元（Sierra BBS 不支援 2400 Baud）。

2. **其他線上服務的提示看板**：
   - **CompuServe**：進入 Gamers Forum（指令 `GO GAMERS`），或到 PC Vendor 底下的冒險遊戲討論區（Jumpword：`PC CLUB`）。
   - **Prodigy**：寫信到 `HTWS90A`，或到 PC Club 進入冒險遊戲討論區。
   - **PCLink**：選 PCLink Plus → Publisher's Connection → Sierra On-Line，可寫信給使用者 ID「Sierra On Li」。

## 磁碟片問題排解（DOS 原版設定，ScummVM 玩家可略）

以下為原版磁片時代的疑難排解建議，純供歷史保存：

1. 若已插入指定磁片、卻仍收到「Insert Disk # __」訊息，可能需要修改 `config.sys`，加入 `FILES=15` 這一行。不熟悉如何修改 `config.sys` 的話，請參閱 DOS 手冊。
2. 若遊戲在任何時間點當機並出現「Out of Handles」或「Out of Heap」訊息，可能是硬碟上常駐了其他記憶體常駐程式（TSR）。請改用僅含 DOS 的開機磁片開機，並視情況依上一條調整 `config.sys`。
